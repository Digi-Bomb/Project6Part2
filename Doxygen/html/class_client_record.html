Detailed Description

ClientRecord class. Private variables listed here:

Parameters
[string]clientID represents the each client's unique ID
[string]planeFileName represents the flight file whose data is being transmitted
[time_t]lastSeen represents the most recent datetime in which the server has received a message from each client
[float]currentAverageFuel maintains the average fuel value of each client transmission
[float]currentConsumption maintains the average fuel consumption of each client
[bool]hasPrevious assures whether or not a client has a previous entry
[int]fuelSumCounter maintains the number of transmissions received from the client
[float]lastFuel maintains the previous fuel consumption average (if it exists)
